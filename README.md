# MediaPro v5.5 — المشغل والعارض الاحترافي ومستكشف الملفات الشامل
### All-in-One Media Player, Pro File Manager & In-App Auto-Updater

تطبيق متكامل لتشغيل وعرض كافة أنواع الوسائط (فيديو، صوت، صور، مستندات، PDF، أكواد برمجية، ملفات مضغوطة) مع نظام مستكشف ملفات حقيقي احترافي للكمبيوتر والهاتف، ومزود بـ **نظام تحديث تلقائي داخلي سلس** يتتبع أحدث الإصدارات من [GitHub Releases](https://github.com/yalaahamdy/MediaPro/releases).

---

## 🚀 التحديث التلقائي الداخلي (In-App GitHub Auto-Updater)

يدعم التطبيق التحديث الذاتي الداخلي على كل من الكمبيوتر والهاتف:
1. **فحص ذكي دوري وفي الخلفية**: يتحقق التطبيق من وجود أي إصدار جديد عبر GitHub API (`https://api.github.com/repos/yalaahamdy/MediaPro/releases/latest`) بصمت بعد بدء التشغيل أو يدوياً من قائمة الإعدادات.
2. **تطبيق الهاتف (Android APK)**:
   - يكتشف الإصدار الأحدث وينزل ملف `MediaPro.apk` مع عرض نسبة التقدم وحجم التنزيل وسرعته.
   - يفتح تلقائياً نافذة تثبيت النظام المعتمدة عبر مزود المحتوى الآمن `FsProvider` دون فقدان أي بيانات أو إعدادات.
3. **تطبيق الكمبيوتر (Windows Portable)**:
   - ينزل ملف التحديث `MediaPro-Windows-Portable.exe` في الخلفية.
   - يقوم باستبدال الملف التنفيذي بأمان عبر سكريبت استبدال غير مقفل وإعادة تشغيل التطبيق تلقائياً بالإصدار الجديد بضغطة زر.
4. **نسخة المتصفح (Web)**:
   - تنبه المستخدم برقم الإصدار وتوفر روابط مباشرة لتنزيل التحديث.

## 📦 حزم التشغيل والتحميل المباشر

- **تطبيق الهاتف**: [`MediaPro.apk`](MediaPro.apk) — ثبت التطبيق وامنح إذن "الوصول لجميع الملفات" للاستمتاع بالمستكشف الكامل.
- **تطبيق الكمبيوتر**: [`MediaPro-Windows-Portable.exe`](MediaPro-Windows-Portable.exe) — تطبيق محمول خفيف لا يحتاج تثبيت.
- **تطبيق الويب المستقل**: [`MediaPro.html`](MediaPro.html) — ملف فردي يعمل على أي متصفح حديث دون إنترنت.

## 🌟 أبرز مميزات الإصدار v5.5

- **مدير ملفات حقيقي متقدم على الكمبيوتر**:
  - استعراض الأقراص المحلية ومحركات الأقراص القابلة للإزالة مع المساحة الفارغة والإجمالية.
  - الوصول السريع (Quick Access) لسطح المكتب، التنزيلات، المستندات، الصور، الفيديوهات.
  - سجل التنقل (Back / Forward) وشريط المسار التفاعلي (Breadcrumbs).
  - البحث العميق المتداخل داخل المجلدات الفرعية.
  - إحصائيات المجلدات الشاملة (Folder Analytics): الحجم الإجمالي، عدد الملفات، التصنيف حسب النوع، وأكبر الملفات.
  - حساب بصمات الملفات والتشفير (MD5, SHA-1, SHA-256).
  - الحذف إلى سلة المحذوفات، فتح موجه الأوامر في المسار الحالي، وإظهار الملف في مستكشف ويندوز.
- **تحديد متعدد وعمليات الملفات الكاملة**:
  - النسخ، القص، اللصق، إعادة التسمية، والحذف بجميع أوضاع العرض (شبكة، قائمة، وبطاقات).
- **محرر نصوص برمجي مدمج**: يدعم الحفظ المباشر للملف الأصلي على القرص مع إبراز الأكواد.
- **مشغل وسائط فائق الإمكانيات**: مشغل فيديو متطور يدعم مسارات الترجمة، السرعات المتعددة، التعادل الصوتي، وضع المسرح و PiP.

## 🛠️ هيكلية الكود البرمجي (Architecture)

```
MediaPro/
├── .github/
│   └── workflows/
│       └── release.yml          # سير عمل GitHub Actions لبناء APK و Portable EXE ونشر الـ Release تلقائياً
├── android/
│   ├── AndroidManifest.xml      # إعدادات الحزمة والأذونات ومزود المحتوى
│   ├── build_apk.bat            # سكريبت بناء وتوقيع APK محلياً (Windows)
│   ├── build_apk.sh             # سكريبت بناء وتوقيع APK في بيئة Linux / CI
│   ├── java/com/mediapro/app/   # كود أندرويد الأصلي (WebView + MediaProFS + In-App Updater)
│   └── res/                     # الموارد والأيقونات الرسمية
├── desktop/
│   ├── package.json             # تعريف حزمة Electron وإعدادات electron-builder
│   ├── main.js                  # عملية Electron الرئيسية ومحرك التحديث والاستبدال
│   ├── preload.js               # الجسر الآمن MediaProFS و MediaProDesktop و MediaProDesktopUpdater
│   ├── build_desktop.bat        # سكريبت تجميع وبناء نسخة الويندوز
│   └── icon.png
├── MediaPro.html                # واجهة وتطبيق الويب الشامل
├── MediaPro.apk                 # تطبيق أندرويد الجاهز
├── MediaPro-Windows-Portable.exe# تطبيق ويندوز المحمول الجاهز
├── .gitignore
└── README.md
```

## 🏗️ خطوات البناء المحلي (Building Locally)

### بناء تطبيق أندرويد (Android APK)
يتطلب توفر Java (JDK 17 أو 21) و Android SDK (Build-Tools & Platform):
```cmd
.\android\build_apk.bat
```

### بناء تطبيق ويندوز (Windows Portable)
يتطلب توفر Node.js:
```cmd
cd desktop
npm install
npm run dist
```
